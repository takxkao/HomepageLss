コース紹介

習熟度や目的に合わせて、3つのコースをご用意しています。

Hello, Programming ( 小学3年生〜 )

スクラッチ(LEGO SPIKE)を使って、レゴブロックでものづくりを楽しみながら論理的思考を育みます。 自分で組み立てたモデルが、自分の書いたプログラムで動き出す体験ができます。 慣れてきたら、プログラミング言語のPythonへ少しずつ進み、自分でコードを書けるところまで目指します。 キーボード操作やマウス操作から丁寧にお伝えするので、パソコンに触れるのが初めてでも大丈夫です。

対象
小学3年生〜(プログラミングが初めての方)
時間
1回60分 / 月2回
使うもの
LEGO SPIKE、レゴブロック、Python(教室で用意します)
身につくこと
論理的思考、順序立てて考える力、Pythonの基礎

Be a Maker

Raspberry Piを使用して電気工作やPythonを使ったプログラミングに挑戦します。 「作りたい物が作れるようになる」ことが目標のコースです。 進度は一人ひとりに合わせて調整します。

対象
「Hello, Programming」修了の方、またはPythonでプログラムが書ける方
時間
1回90分 / 月2回
使うもの
Raspberry Pi / Python / 電子部品(教室で用意します)
身につくこと
実践的なコーディング力、問題を分解して解決する力

For Adult ( 18歳以上 )

お仕事の効率化や趣味の制作など、目的に合わせて学習内容を組み立てます。 「何から始めればいいかわからない」という段階からのご相談も歓迎です。 平日夜・土日の時間帯もご用意しています。

対象
18歳以上の方
時間
1回90分 / 月1回
使うもの
ご希望に応じて相談(Python、Excel VBA、Raspberry Pi など)
身につくこと
業務効率化のスキル、自分で調べて作れる力
